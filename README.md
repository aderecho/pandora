# FileServer Platform

Enterprise-grade, self-hosted, S3-style file storage platform.

- `api/` — Laravel REST API (buckets, objects, tokens, audit logs)
- `admin/` — Vue 3 + TypeScript + Tailwind admin dashboard
- `cli/` — `narrasoft/fileserver-cli` Composer CLI package
- `docs/` — architecture, ERD, deployment, and API examples

Full documentation is being written module by module; see `docs/` as phases land.
